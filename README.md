### 🧭 How I work

- **Measure first.** Every model ships with a baseline, a metric that matters to the business, and an honest error analysis.
- **Local by default.** If data is sensitive, it shouldn't leave the device. I reach for Ollama and on-prem stacks before cloud APIs.
- **Guardrails are features.** Input sanitisation, injection defences and fallbacks are part of the build, not an afterthought.
